# Adam Bomb's frames for Razor Ramon's animation groups (mods/adambomb/README.md).
#
# Adam is played with Razor's moves (his own code in orig/ADAM.ASM is for an older engine). Every
# group of Razor frames the game uses gets a copy for Adam, AB<rest of the name> (R4ST4G -> AB4ST4G),
# with as many frames as Razor's. A line here fills it from one of Adam's own groups in IMG/ADAM.LOD
# (picked by looking at the frames side by side: the same pose, seen from the same side):
#
#   RAZOR  ADAM  [frame frame ...]
#
# Without a frame list Razor's frame k becomes Adam's frame round(k * adam_count / razor_count).
# With one, the n-th number is Adam's frame for Razor's frame n (0: none, Razor has no frame there).
# "align" (before the list) is for groups where Adam's pictures sit elsewhere around their anchor than
# Razor's (in the air, falling, lying: up to 50 pixels): his frames get copies (AY...) with the anchor
# moved so that his body is where Razor's was (the feet where both stand, else the middle of the body).
# Groups not listed borrow Razor's frames, recoloured to Adam's palette (AZ<rest>, made by mkadam.py).
