# Security

This is a game port that runs locally and reads files from your own disk (the original game's data, optional art and
sound files, `wwf.cfg`). If you find a way to make it crash or run code through a crafted data file or settings file, or
any other security problem, please report it privately and not as a public issue:

use **Security → Report a vulnerability** on the repository's GitHub page (GitHub's private vulnerability reporting).

Please say what you ran it on, which file or setting triggers it, and what happens. Reports are looked at as time allows.
